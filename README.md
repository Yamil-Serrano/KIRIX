# KIRIX

**Kore Integrated Reduced Instruction eXperiment**

KIRIX is an experimental 16-bit FPGA CPU architecture written in Verilog.

The objective of KIRIX is to explore a clean and efficient processor architecture where every instruction justifies its hardware cost. Instead of maximizing the number of instructions, KIRIX focuses on a carefully designed instruction set that remains practical, extensible, and easy to understand.

## Project Goals

- Design a 16-bit CPU architecture from scratch.
- Implement the processor entirely in Verilog.
- Develop a compact and efficient ISA.
- Build a custom assembler.
- Provide a foundation for future operating systems, applications, and low-poly 3D graphics.
- Explore future hardware extensions such as dedicated coprocessors or AI accelerators.

> **Every instruction should have a purpose.**
